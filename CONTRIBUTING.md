# Contributing

Open pull requests against `edge`, including fixes and documentation. GitHub's
default branch is `main`, so select `edge` as the PR base when opening a PR.
`main` and `stable` receive reviewed promotions only. The
[channel policy](docs/development.md#edge-main-and-stable) explains the process.

Keep PRs focused. Describe the change and how you checked it; the
[development guide](docs/development.md) lists local verification commands.

If an AI model helped, naming the model and its reasoning effort (if available)
in the PR description is appreciated, but optional.

Report bugs and proposals in [GitHub Issues](https://github.com/Yazelix/nova/issues).
Participation follows the [Code of Conduct](CODE_OF_CONDUCT.md).
